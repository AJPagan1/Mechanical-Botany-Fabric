# Create: Mechanical Botany

A Fabric port of **Create: Mechanical Botany** for Minecraft 1.20.1.

## About

Create: Mechanical Botany adds Create-powered automation for gathering and processing plant-related resources.

This Fabric port preserves the original Mechanical Composter and Mechanical Insolator systems, including their recipes, integrations, JEI support, Ponder scenes, animations, and Create automation behavior.

## Original Project

Original mod by **DakotaPride**.

This project is a Fabric port of the original NeoForge version of Create: Mechanical Botany.

## Fabric Port

Fabric port by **Pagan**.

## Features

- Mechanical Composter
- Mechanical Insolator
- Create automation support
- JEI recipe integration
- Ponder scenes
- Original Composting recipes
- Original Insolating recipes
- Integration recipes for supported mods
- Fabric 1.20.1 support

## Requirements

- Minecraft 1.20.1
- Fabric Loader
- Fabric API
- Create Fabric

## Optional Integrations

Mechanical Botany includes recipes for supported integration mods when those mods are installed.
